Manual Login Testing
Project Overview

This project demonstrates a manual QA testing workflow for a web application's login functionality.

The goal is to practice designing test cases, executing positive and negative tests, documenting expected and actual results, and identifying software defects.

Testing Scope

The login functionality will be tested for:

Valid login credentials
Invalid username
Invalid password
Blank username
Blank password
Both fields blank
Invalid email formats
Password field behavior
Login error messages
Login button behavior
Boundary and negative cases
Testing Approach

Testing will include:

Functional testing
Positive testing
Negative testing
Boundary testing
Validation testing
UI testing
Test Environment

Application: Public web-based demo application
Browser: Chrome
Operating System: Windows
Testing Type: Manual testing

Deliverables
Test cases
Test execution results
Bug reports
Testing observations
Final testing summary
